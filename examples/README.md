# Examples

Each folder is a standalone script. From the example directory:

```bash
npm install
npx tsx index.ts
```

| Folder | Command env |
|--------|-------------|
| `quickstart/` | `VEYA_API_URL`, `VEYA_API_KEY` |
| `anchor-proof/` | `VEYA_API_URL`, `VEYA_API_KEY` |
| `wallet-auth/` | `VEYA_API_URL`, wallet signer |
| `protected-execution/` | `VEYA_API_URL`, `VEYA_API_KEY`, `ENV_ID`, `AGENT_ID` |
| `deploy-agent/` | `VEYA_API_URL`, `VEYA_API_KEY`, `ENV_ID` |
| `memory-scope/` | `VEYA_API_URL`, `VEYA_API_KEY`, `ENV_ID` |
